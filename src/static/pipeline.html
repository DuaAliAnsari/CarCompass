System design

From two listing files to one price.

Training is offline. A request only loads a saved model. The written version is in design/SYSTEM_DESIGN.md.

  1. 01Listings

    Dataset A is a CSV. Dataset B is JSON. Both are downloaded, not committed.

  2. 02Prepare

    Map columns, drop bad prices and duplicates, scale B to A, write one split.

  3. 03Train

    Five families, twelve runs. MLflow records parameters, MAE, and the git commit.

  4. 04Choose

    Lowest validation MAE under 100 MB. The test set is not used to pick.

  5. 05Serve

    FastAPI loads the manifest and routes on the car's year.

  6. 06Range

    Calibration quantiles. Each assumed field widens that range by 10%.

  7. 07Watch

    /health and /metrics. Counts live in memory and reset on restart.

  8. 08Ship

    One Docker image. It predicts only when the joblib files were copied in.

Design notes live in design/SYSTEM_DESIGN.md and design/UI.md.
